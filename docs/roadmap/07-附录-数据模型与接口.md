# 07 · 附录：数据模型与接口契约

> 本附录汇总所有新增表的 DDL、接口契约与配置项，供开发直接使用。
>
> 约定（沿用 kamihub 现有规范，见 `docs/DATABASE.md`）：
> - 整数列 GORM 映射为 `bigint`，不用 `integer`
> - 金额统一 `numeric(p,2)`，Go 侧 `shopspring/decimal`，**不用浮点**
> - 时间列全部 `timestamptz`（库内 UTC，容器 `TZ=Asia/Shanghai`）
> - 无软删除，`Delete()` 为真实 DELETE
> - 表名复数下划线；主键 `<table>_pkey`；索引 `idx_<table>_<col>`

### 3.8 `price_tiers` 档位定义 ★

```sql
CREATE TABLE price_tiers (
  id                  bigserial PRIMARY KEY,
  code                varchar(32) NOT NULL UNIQUE,   -- retail/bronze/silver/gold/diamond
  name                varchar(64) NOT NULL,

  -- 达成条件（满足任一即可）

  enabled             boolean NOT NULL DEFAULT true,
  remark              varchar(255),
  created_at          timestamptz NOT NULL DEFAULT now(),
  updated_at          timestamptz NOT NULL DEFAULT now()
);
CREATE INDEX idx_pt_enabled ON price_tiers (enabled, sort_order);
```

### 保底公式（代码实现）

```go
// 计算某商品的档位专价
func calcTierPrice(listing *Listing, cost decimal.Decimal, tier *PriceTier, feeRate decimal.Decimal) (decimal.Decimal, error) {
    // 1. 按折扣率算
    price := listing.SalePrice.Mul(tier.DiscountRate)

    // 2. 保底①：不得低于成本 × (1 + min_margin_rate)
    floorA := cost.Mul(decimal.NewFromInt(1).Add(tier.MinMarginRate))

    // 3. 保底②：扣手续费后净利率不得低于 2%
    //    net = price - cost - price*feeRate >= listing.SalePrice * 0.02
    //    price*(1-feeRate) >= cost + retail*0.02
    //    price >= (cost + retail*0.02) / (1-feeRate)
    numerator := cost.Add(listing.SalePrice.Mul(decimal.NewFromFloat(0.02)))
    floorB := numerator.Div(decimal.NewFromInt(1).Sub(feeRate))

    floor := decimal.Max(floorA, floorB)
    if price.LessThan(floor) {
        // 该档位对该商品不可用，调用方应逐级回落到上一档
        return decimal.Zero, ErrTierNotViable
    }
    return price.Round(2), nil
}
```

> **逐级回落**：`BuyerQuote` 里若当前档位不可用，按 `sort_order` 递减尝试，
> 最终回落到 `retail`。不要整单失败。

## 八、给开发的三条硬提醒

1. **`calcTierPrice` 的保底必须有，且必须逐级回落。**
   不同商品成本不同，同一个档位对便宜商品可行、对贵商品可能亏本。
   少了回落逻辑，会出现「某商品代理价低于成本」的资损。

2. **档位统计必须排除自购与退款订单。**
   否则销售自己刷单就能冲上金牌，长期拿低价。

3. **金额一律用 `decimal`，禁止 `float64`。**
   kamihub 现有代码已经严格遵守，新增代码不要破坏这个惯例。
   一个 `float64` 的价格误差，累积一年就是财务对不上账。
